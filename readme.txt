Curated collections of posts, managed from a dashboard and shown in a streaming-style browser block.

== Description ==

Collections Manager stores curated collections of posts, lets editors build and order them from the Collections dashboard, and shows them on the site through the Collections Browser block: a rail of collections that opens into a post carousel.

Updates are delivered from updates.bemistech.com.
